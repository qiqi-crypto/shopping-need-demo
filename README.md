# 生活选物 · Shopping need demo

Research interface preview; no checkout or payment.

Catalog metadata: [Amazon Reviews 2023, McAuley Lab](https://amazon-reviews-2023.github.io/). Images follow the corresponding source product records. USD prices are original crawl-time listings, not live offers. Chinese text is machine-translated with Qwen3-8B and Qwen3.5-9B; originals are retained. CNY figures are explicitly labeled conversions at USD/CNY 6.6751 (2026-11-06), from Exchange Rates UK, not China retail offers.

No missing prices, reviews or product features are fabricated. Browser records stay in localStorage unless the visitor exports them. No server credentials, questionnaire responses, GPU jobs or private research model documents are included in this repository.
